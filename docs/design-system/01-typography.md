# Typography

**Font families**

| Role                       | Font       | CSS variable        |
| -------------------------- | ---------- | ------------------- |
| Sans (default)             | Geist Sans | `--font-geist-sans` |
| Mono (code, dates, labels) | Geist Mono | `--font-geist-mono` |

**Type scale**

| Token     | Size                         | Weight | Line-height | Usage                               |
| --------- | ---------------------------- | ------ | ----------- | ----------------------------------- |
| `display` | 48px / 3rem (36px on mobile) | 600    | 1.1         | Hero heading                        |
| `h1`      | 30px / 1.875rem              | 600    | 1.2         | Page titles                         |
| `h2`      | 24px / 1.5rem                | 600    | 1.3         | Section titles                      |
| `h3`      | 16px / 1rem                  | 500    | 1.4         | Card / list item titles             |
| `body`    | 16px / 1rem                  | 400    | 1.6         | Paragraph text                      |
| `small`   | 14px / 0.875rem              | 400    | 1.5         | Secondary text, meta, labels        |
| `eyebrow` | 14px / 0.875rem              | 500    | 1.4         | Section labels (uppercase optional) |

**Letter-spacing:** tight (`-0.01em`) on headings, normal on body text.

# Buttons & Interactive States

| Variant   | Background   | Text         | Border   | Hover                      |
| --------- | ------------ | ------------ | -------- | -------------------------- |
| Primary   | `foreground` | `background` | none     | `opacity: 0.9`             |
| Secondary | transparent  | `foreground` | `border` | `surface-muted` background |

**Focus ring (all interactive elements):** 2px solid `accent`, 2px offset.

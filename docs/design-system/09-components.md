# Components

Patterns to reuse rather than reinvent per section:

- **Section wrapper** — top border, `space-xl` vertical padding, eyebrow + `h2` heading
- **Card** — `radius-md` border, `space-md` padding, border-color transition on hover
- **Tag/pill** — `radius-full`, `surface-muted` background, `small` text, `space-xs` horizontal padding
- **Nav link** — `small` text, `foreground/70` default, `foreground` on hover/active

# Spacing

Base unit: `4px`. Use Tailwind's default scale (`gap-1` = 4px … `gap-20` = 80px).

| Token      | Value | Usage                                  |
| ---------- | ----- | -------------------------------------- |
| `space-xs` | 8px   | Tag padding, tight gaps                |
| `space-sm` | 16px  | Icon-to-text gap, small stacks         |
| `space-md` | 24px  | Card padding, form field gaps          |
| `space-lg` | 40px  | Gap between sub-blocks in a section    |
| `space-xl` | 80px  | Vertical padding between page sections |

**Container:** max-width `1024px` (`max-w-4xl`), horizontal padding `24px` (`px-6`).
